أنت على لابتوب موصول بسيارة هافال H9 موديل 2026. المطلوب تنظيف تطبيقات وحدة الشاشة (HUT).

اقرأ مهارة haval-hut-adb-cleanup أولًا واتبعها حرفيًا.

نفّذ المرحلة الأولى فقط — قراءة، بلا أي تعديل:

1) تأكد أن adb موجود:
     adb version
   لو غير موجود: brew install --cask android-platform-tools

2) اقتران اللابتوب بالشاشة:
     cd ~/Documents/haval-hut
     bash hut-pair.sh
   - لو ظهرت نافذة تصريح على شاشة السيارة، اطلب مني قبولها
   - لا تكرر المحاولة أكثر من ٣ مرات

3) الفحص:
     bash hut-scan.sh

4) اطبع لي في النهاية:
   - الموديل وإصدار أندرويد الموجود في التقرير
   - عدد حزم النظام وعدد حزم الطرف الثالث
   - مسار ملف hut-report-....txt
   - أي رسالة خطأ ظهرت حرفيًا


قواعد إلزامية — لا تُخالف أي واحدة:

• قراءة فقط. لا تنفّذ أي أمر فيه install أو uninstall أو push أو disable أو write.
• لا تضغط ولا تقترح أي زر في برنامج التشخيص: Write Configure · Write Vehicle Model · Write VIN · Write System Configuration · Write instrument panel network · After-sale Matching Function · Set Production Mode.
• لا تمسّ وحدة لوحة العدادات ولا أي بند فيه Total mileage reset.
• لا تفتح أي منفذ في الشبكة ولا تعدّل sshd ولا أي إعداد نظام.
• لا تنفّذ hut-clean.sh إلا بعد أن أعطيك قائمة الحزم بموافقتي الصريحة، وبعد أن تسجّل حالة كل حزمة أولًا.
• لو واجهت خطأ غير متوقع: توقف واعرضه لي. لا تجرّب حلولًا من عندك.

لغتك: عربي، مختصر، عملي.
