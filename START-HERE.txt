ابدأ من هنا — حزمة تنظيف شاشة هافال (HUT)
==========================================

الملفات الموجودة في هذي الحزمة:

  SETUP.md         ← اقرأه أولًا (طريق 2026 المؤكّد + الشروط)
  GUIDE.md         ← قواعد السلامة + ما لا يُلمس
  remove.txt       ← القائمة اللي تعبّيها بأنواع الحزم (يأتي معها شرح)
  hut-pair.sh      ← اقتران اللابتوب بالشاشة
  hut-scan.sh      ← الفحص (قراءة فقط)
  hut-clean.sh     ← التعطيل (مع سجل رجوع)
  hut-restore.sh   ← الرجوع
  haval-setup.sh   ← لو احتجت تنزيل الحزمة من الإنترنت مرة ثانية


التشغيل بالترتيب
----------------

1) تجهيز adb (على المك):

     brew install --cask android-platform-tools
     adb version

2) افتح المجلد في الطرفية:

     cd ~/Downloads        # أو مكان الحزمة بعد فك الضغط
     chmod +x *.sh

3) الاقتران بالشاشة (الشروط الخمسة تظهر على الشاشة):

     bash hut-pair.sh

4) الفحص — قراءة فقط، صفر تعديل:

     bash hut-scan.sh

   يكتب ملفًا اسمه hut-report-....txt
   أرسل هذا الملف للوكيل → يرد عليك بقائمة الحزم غير الأصلية.

5) التعطيل (بعد المراجعة):

     bash hut-clean.sh
     # اكتب  DISABLE  للتأكيد

6) الرجوع (في أي وقت):

     bash hut-restore.sh
     # اكتب  RESTORE  للتأكيد


⛔ لا تلمس أبدًا (في برنامج التشخيص)
-------------------------------------
  Write Configure · Write Vehicle Model · Write VIN
  Write System Configuration · Write instrument panel network
  After-sale Matching Function

  وحدة لوحة العدادات (ICM/IP) فيها بند  Total mileage reset
  = تصفير إجمالي العداد. ممنوع قانونيًا وغير قابل للرجوع.


ضمانات السكربتات
----------------
  • لا حذف · لا إلغاء تثبيت · لا كتابة إعدادات
  • التعطيل فقط (pm disable-user) — وكل حزمة تُسجَّل قبل التعطيل
  • ترفض العملية كلها لو في القائمة حزمة نظام أو حزمة تتعلق بالسيارة
  • تطلب تأكيدًا كتابيًا قبل أي تغيير


للاستفسار: أرسل للوكيل ملف hut-report-....txt أو أي صورة من الشاشة.
